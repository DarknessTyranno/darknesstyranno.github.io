SpriteLess UI

Everyday UI shapes, without sprite files. Create and customize geometry-based graphics directly in Unity's uGUI.

Unity 2021.3 LTS+uGUIRuntime-ready
View on GitHub ↗Installation

Keep the simple things simple

Choose a shape. Make it yours.

01 / Shape

More than rectangles

Rounded rectangles, pills, circles, ellipses, rings, arcs, triangles, chevrons and regular polygons. Per-corner offsets also create trapezoids and parallelograms.

02 / Style

Adjust in the Inspector

Control fill colors, corner radii, inside borders and anti-aliasing. Add directional edge color for a little depth, or assign a compatible custom UI material.

03 / Integrate

Fits into uGUI

Use RectTransforms, layout groups, buttons and sliders. Supports Mask and RectMask2D, plus shape-aware raycasts for non-rectangular graphics.

No custom shader or generated texture required. Default graphics use the shared UI material. SpriteLess UI is a runtime shape component, not an image-baking tool.

Get started

Install from a Git URL.

In Unity's Package Manager, choose Add package from git URL and paste:

https://github.com/DarknessTyranno/SpriteLess-UI.git?path=/Packages/io.github.darknesstyranno.spriteless-ui

Create a shape from GameObject → UI (Canvas) → SpriteLess, or add SpriteLessImage to a UI GameObject. Choose the shape and adjust its settings in the Inspector.

Requirements

  • Unity 2021.3 LTS or newer.
  • Unity UI (uGUI) 1.0.0 or the version bundled with your Editor.
  • Git 2.14 or newer for Git URL installation.

Open source

  • Released under the MIT license.
  • No TextMeshPro or Scriptable Render Pipeline dependency.
  • Read the package documentation for the full feature list and usage notes.
